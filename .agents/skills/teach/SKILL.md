# Teach

Ground explanations in the project's actual code and requirements. Choose one
concept from the user's request, explain its purpose and execution path, then
offer a small prediction or reasoning exercise. Show relevant files/symbols
and distinguish implemented behavior from planned features.

For coursework preparation, connect TCP framing, server privacy, thread/strand
ownership, SQLite acceptance, or TLS verification to the relevant R requirement
and demonstration evidence. Check the user's reasoning and explain the missing
step without turning every interaction into an interview.

Keep this a learning task; application edits, new features, slides, or recurring
practice require the corresponding request. Preserve useful API/test comments
and do not copy a textbook when the actual execution path explains the concept.
