# Optional task record

Use for a substantial or multi-session task, saved under
`.cache/workflow/tasks/<short-task-name>.md` unless a durable project doc is
needed. A small task can keep this information in the working plan/reply.

- Request, scope, and affected existing requirement IDs/contracts.
- Task-start Git status, owned files, and pre-existing failures/work.
- Observable acceptance criteria and public tests/proofs for each.
- Design choice, alternatives worth considering, ownership/cancellation/limits.
- Additional verification chosen or omitted and the actual reason.
- Commands/results/evidence paths; unproved manual or environmental criteria.
- Review findings/repairs, refactor evaluation, and remaining next action.

Reference existing architecture, plan, requirements, and progress rather than
copying them. Never store tokens, credentials, real chats, or an environment dump.
