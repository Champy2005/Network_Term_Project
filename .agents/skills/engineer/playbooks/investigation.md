# Investigation

1. State the question and what observation would answer it. Keep application
   files unchanged unless the user also authorized a fix or experiment.
2. Read the relevant requirements, callers, ownership, and tests. For external
   facts use current primary documentation and cite it.
3. Run a bounded, isolated observation if static evidence cannot decide the
   question. Respect read-only scope; use disposable evidence for experiments.
4. Return a cited explanation or options with tradeoffs, separating observed
   facts, inference, and unknowns. Do not turn an explanation into a rewrite.
